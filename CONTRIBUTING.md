# Contributing / 贡献说明

## English

Thank you for your interest in Yank Note. Issues, bug reports, feature requests, and suggestions are welcome. We do not directly accept external code contributions or code pull requests.

Yank Note is open source, and some features are paid. The maintainer is responsible for the product's direction, implementation, and ongoing maintenance. AI tools have made producing code much easier, while carefully reviewing changes, checking compatibility, and maintaining them over time still require substantial effort. We therefore focus our review and maintenance capacity on code developed within the project.

If you have a good idea, please open an issue to describe the use case and the problem you would like to solve. For bug reports, include your Yank Note version, operating system, steps to reproduce, and the expected and actual behavior. Please check for an existing discussion before opening a new issue.

Thank you for helping improve Yank Note through feedback and discussion.

## 中文

感谢你关注 Yank Note。欢迎通过 Issue 提交问题反馈、Bug 报告、功能建议和好的想法。我们不直接接受外部代码贡献或代码 Pull Request。

Yank Note 是开源项目，同时包含部分付费功能。项目的产品方向、功能实现及后续维护由维护者负责。AI 工具让编写代码变得更加容易，但认真审查改动、验证兼容性以及承担长期维护，仍然需要投入大量精力。因此，我们会将有限的审查和维护精力集中在项目内部实现的代码上。

如果你有好的想法，欢迎通过 Issue 说明使用场景和希望解决的问题。报告 Bug 时，请提供 Yank Note 版本、操作系统、复现步骤，以及预期行为和实际行为。提交新 Issue 前，请先检查是否已有相关讨论。

感谢你通过反馈和讨论帮助 Yank Note 改进。
